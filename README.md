# RSS Studio — Site Vitrine

Site vitrine moderne et premium pour **RSS Studio**, spécialisé dans la fabrication et l’aménagement sur mesure.

## Services

-  Cuisines équipées
-  Dressings
-  Placards
-  Habillages muraux
-  Portes
-  Réalisations sur mesure

## Fonctionnalités

- Design moderne et haut de gamme
- 100 % responsive
- Galerie des réalisations
- Présentation des services
- Formulaire de contact
- Intégration WhatsApp et appel
- Localisation avec Google Maps
- Animations et transitions fluides

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase

## Développement

```bash
npm install
npm run dev
```
